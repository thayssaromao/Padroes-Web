# Imagens do Portal do Artesão

Todas as imagens abaixo são **placeholders** (cinza com o nome do arquivo). Para usar a foto real, **salve-a com exatamente o mesmo nome e extensão** na mesma pasta. Nenhum código precisa mudar.

Dicas:
- Formato `.jpg`, qualidade ~80%. Tente manter cada arquivo abaixo de **300 KB** (o limite de mídia no repositório é 2 MB; vídeos vão para o YouTube).
- Mantenha a proporção indicada; o CSS recorta o excesso (`object-fit: cover`), centralizado.
- O texto alternativo (`alt`) está no HTML ou no JSON de dados; ajuste-o se a foto mudar de assunto.
